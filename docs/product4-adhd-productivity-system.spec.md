# 3. Module Structure

## MODULE 1: Understand Your Productivity Patterns

### Outcome
Create a Personal Productivity Profile.

### Lessons

#### 1.1 Why Productivity Systems Fail
A productivity system can fail because it requires too many decisions, too many steps, too much maintenance, or too much consistency.

The goal is not to create the most sophisticated system. The goal is to create a system you can return to when life becomes messy.

A useful system should answer:

1. What do I need to remember?
2. What matters now?
3. What is the next action?
4. When will I work on it?
5. What needs reviewing?

**Action:** List three parts of your current system that create friction.

#### 1.2 Your Productivity Friction Audit
Identify where work breaks down:
- Capture
- Organization
- Prioritization
- Starting
- Focus
- Time estimation
- Scheduling
- Completion
- Reviewing
- Environment

**Worksheet:** Rate each area 1–5 and identify the three highest-friction areas.

#### 1.3 Build Your Personal Productivity Profile
Record:
- Common distractions
- Typical energy patterns
- Tasks you avoid
- Situations where you focus well
- Things you frequently forget
- Planning methods that have failed
- Planning methods that have helped

**Output:** Personal Productivity Profile.

### Quiz
1. What is the primary purpose of a productivity system?
A. To schedule every minute  
B. To make important actions easier to identify and execute  
C. To eliminate all distractions  
D. To maximize working hours

Correct: B.

## MODULE 2: Capture Everything

### Outcome
Create one trusted capture system.

### Lessons

#### 2.1 The Open-Loop Problem
Unfinished tasks consume attention when your brain keeps trying to remember them.

Capture removes the need to repeatedly remember.

#### 2.2 What Belongs in Your Capture System
Capture:
- Tasks
- Ideas
- Appointments
- Commitments
- Questions
- Things to buy
- Projects
- Follow-ups
- Important information

Do not immediately organize everything. Capture first.

#### 2.3 Build Your Master Capture List
Create one list containing everything currently occupying mental space.

Then classify each item:
- Task
- Project
- Appointment
- Idea
- Reference
- Waiting
- Someday

**Output:** Master Capture List.

### Exercise
Set a 10-minute timer and perform a complete brain dump.

---

## MODULE 3: Prioritize What Matters

### Outcome
Create a realistic priority list.

### Lessons

#### 3.1 Not Everything Is a Priority
A priority is something that deserves attention relative to other available choices.

Use four categories:
- Must
- Should
- Could
- Not now

#### 3.2 Priority Signals
Consider:
- Deadline
- Consequence
- Importance
- Opportunity
- Effort
- Energy
- Dependency

Do not confuse urgency with importance.

#### 3.3 Create Your Weekly Priority List
Choose:
- 1–3 major outcomes
- Supporting tasks
- Optional tasks
- Things deliberately deferred

**Output:** Weekly Priority List.

### Challenge
Take your current task list and reduce it to the smallest list that still represents what matters.

---

## MODULE 4: Turn Tasks Into Actions

### Outcome
Build a Next-Action System.

### Lessons

#### 4.1 Tasks vs Projects
"Launch my business" is a project.

"Open the domain registrar and compare three domain names" is an action.

#### 4.2 The Next Action Rule
If you do not know how to start, the task is probably not specific enough.

Use:

**Verb + object + clear finish**

Examples:
- Draft the first paragraph of the proposal.
- Email Sarah the revised quote.
- Open the spreadsheet and enter March expenses.

#### 4.3 Break Down Overwhelming Tasks
Use:
**Outcome → Milestone → Task → Next Action**

**Output:** Next-Action List.

### Worksheet
For five difficult tasks:
- Desired outcome
- Why it matters
- First physical/digital action
- Estimated effort
- Possible blocker
- Smaller version

## MODULE 5: Start Tasks

### Outcome
Create a Start Now system.

### Lessons

#### 5.1 Starting Is Its Own Skill
You do not need to feel ready before beginning.

Reduce the distance between deciding and doing.

#### 5.2 The Five-Minute Start
Commit to beginning for five minutes.

The objective is not to finish. It is to cross the starting threshold.

#### 5.3 Remove Starting Friction
Before starting:
- Open the required file
- Put materials within reach
- Close irrelevant tabs
- Silence unnecessary notifications
- Decide the first action
- Set a short focus period

#### 5.4 Body Doubling and External Cues
Some people work better when another person is present or when a visible cue marks the beginning of work.

Use external structure where it helps.

**Output:** Start Now Decision Card.

### Start Now Card
1. What am I starting?
2. What is the first action?
3. What can I remove from the environment?
4. What is my minimum commitment?
5. What happens immediately after I start?

## MODULE 6: Focus & Distraction

### Outcome
Build a Focus System.

### Lessons

#### 6.1 Design the Environment
Focus is affected by:
- Notifications
- Open tabs
- Phone proximity
- Noise
- Visual clutter
- Unclear tasks
- Interruptions

Change the environment before demanding more concentration.

#### 6.2 Single-Tasking
Choose one defined outcome for a focus session.

Avoid turning a focus session into a vague instruction such as "work."

#### 6.3 Focus Sessions
Create a repeatable cycle:
**Define → Prepare → Focus → Break → Review**

The duration should be adjustable rather than treated as a universal rule.

#### 6.4 Distraction Log
Record distractions without judging them.

Track:
- What happened?
- What triggered it?
- What did I do?
- What could make the next session easier?

**Output:** Focus System + Distraction Log.

## MODULE 7: Time Blocking & Flexible Scheduling

### Outcome
Create a Flexible Daily Planner.

### Lessons

#### 7.1 Time Is a Constraint
A task list tells you what exists. A schedule gives important work a place.

#### 7.2 Use Flexible Blocks
Instead of scheduling every minute, create blocks such as:
- Deep work
- Admin
- Communication
- Errands
- Recovery
- Personal

#### 7.3 Add Buffers
Plans fail when there is no room for interruptions, transitions, or overruns.

#### 7.4 Recover From a Broken Plan
When the day changes:
1. Stop
2. Reassess
3. Keep the most important item
4. Move lower-priority work
5. Continue

**Output:** Flexible Daily Planner.

---

## MODULE 8: Energy-Based Planning

### Outcome
Create an Energy Planner.

### Lessons

#### 8.1 Match Work to Available Energy
Categorize tasks:
- High energy
- Medium energy
- Low energy

#### 8.2 Build Task Menus
High energy:
- Writing
- Strategy
- Complex problem-solving

Medium:
- Meetings
- Editing
- Planning

Low:
- Filing
- Admin
- Simple replies
- Routine tasks

#### 8.3 Track Patterns
Do not assume your energy pattern. Observe it.

**Output:** Energy Planner.

## MODULE 9: Projects & Long-Term Goals

### Outcome
Create a Project-to-Action Map.

### Lessons

#### 9.1 Goal → Project → Milestone → Task → Next Action
A goal describes direction.

A project produces an outcome.

A task moves the project.

A next action tells you what to do now.

#### 9.2 Limit Active Projects
Too many active projects increase switching and ambiguity.

Create:
- Active
- Waiting
- Someday

#### 9.3 Project Dashboard
For every active project record:
- Outcome
- Deadline if relevant
- Current milestone
- Next action
- Blocker
- Status

**Output:** Project Dashboard.

The system needs maintenance.

A reset is not a performance review. It is a way to restore clarity.

#### 10.2 Weekly Reset Questions
- What did I complete?
- What remains?
- What changed?
- What is no longer important?
- What am I waiting for?
- What matters next?
- What should I remove?

#### 10.3 Rebuild the Week
Create:
- Top outcomes
- Important tasks
- Appointments
- Projects
- Personal commitments
- Recovery time

**Output:** Weekly Reset Dashboard.
